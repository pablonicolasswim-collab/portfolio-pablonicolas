## Tecnologías

- HTML5 semántico.
- CSS3 en `css/estilos.css`.
- Bootstrap **5.3.8** y Bootstrap Icons mediante CDN.
- JavaScript sencillo en `js/main.js` para el formulario.

## Paleta de colores y contraste

| Uso | Color | Combinación | Contraste aproximado |
| --- | --- | --- | --- |
| Principal | `#164B82` | Texto blanco `#FFFFFF` | **8,9:1** |
| Principal para enlaces | `#164B82` | Fondo blanco `#FFFFFF` | **8,9:1** |
| Fondo de portada | `#EEF4FA` | Texto oscuro `#212529` | **13,9:1** |
| Texto general | `#212529` | Blanco `#FFFFFF` | **15,4:1** |

Se usan estos colores con blanco, negro y grises de Bootstrap. Los contrastes de la tabla son cálculos aproximados; para la comprobación definitiva se debe utilizar WebAIM Contrast Checker. Uso Arial como tipografía.


## Uso de IA

He utilizado IA como apoyo para preparar la estructura inicial del portfolio y para comprender y aplicar partes de la segunda entrega, especialmente la validación del formulario, el modal de Bootstrap y algunos aspectos de accesibilidad y organización del CSS. El código está planteado con HTML, CSS y JavaScript básicos.
