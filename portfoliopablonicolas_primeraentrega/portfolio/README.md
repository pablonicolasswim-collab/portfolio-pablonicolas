# Portfolio profesional - Pablo Bonilla

Portfolio realizado para la primera entrega de Diseño de Interfaces Web (DAW).

## Tecnologías
HTML5, CSS3, Bootstrap 5.3 y Bootstrap Icons.

## Secciones
Sobre mí, habilidades, proyectos, formación y experiencia y contacto.

## Estructura
- `index.html`: página principal.
- `css/estilos.css`: estilos básicos.
- `js/main.js`: reservado para la siguiente entrega.
- `img/`: avatar y vistas ilustrativas de los proyectos.
- `docs/`: carpeta para el CV definitivo de la segunda entrega.

## Antes de publicar
1. Sustituir `TU-USUARIO` por mi usuario real de GitHub y añadir los enlaces reales de cada proyecto.
2. Sustituir `TU-PERFIL` y `TU-CORREO@ejemplo.com` por mis datos profesionales.
3. Cambiar las imágenes ilustrativas por capturas reales de los proyectos cuando estén disponibles.
4. Añadir `docs/cv.pdf` cuando esté preparado el CV definitivo (entrega 2).
5. Subir los archivos de esta carpeta a un repositorio público llamado `portfolio`, con `index.html` en la raíz.
6. En GitHub: **Settings > Pages > Deploy from a branch > main > / (root)**.

**Web publicada:** pendiente de configurar en GitHub Pages.

**Nota:** el formulario está solo maquetado: todavía no envía mensajes ni tiene validación, porque eso corresponde a la siguiente entrega.
